# 模拟测试板

## 页面目标

完成一块独立双层 PCB，用 12 个精密电阻模拟 PT100 在不同温度下的阻值。原理图按本页逐个元件放置和连线；核心要求是任意挡位只有一个电阻被接入，避免多电阻并联。

| 项目 | 内容 |
| --- | --- |
| 板名 | `模拟测试板` |
| 功能 | 板载精密电阻替代三线制 PT100 |
| 挡位 | 12 挡，基础 6 点 + 进阶 6 点 |
| 选档机构 | 推荐 `2x12 2.54mm 排针 + 单个短路帽`；旋钮式可选 `2P6T + SPDT` |
| 电阻 | 0603 精密电阻，10ppm/°C，按图片样品包阻值实装 |
| 丝印 | `模拟测试板 队伍编号 2026-05` |

## 固定网络名

| 网络名 | 含义 |
| --- | --- |
| `WHITE_OUT` | 接采样板 `WHITE` |
| `RED_KELVIN` | 所有电阻红线公共端，同时直接接 J1-2 和 J1-3 |
| `RSEL_1` | 选档第 1 挡输出 |
| `RSEL_2` | 选档第 2 挡输出 |
| `RSEL_3` | 选档第 3 挡输出 |
| `RSEL_4` | 选档第 4 挡输出 |
| `RSEL_5` | 选档第 5 挡输出 |
| `RSEL_6` | 选档第 6 挡输出 |
| `RSEL_7` | 选档第 7 挡输出 |
| `RSEL_8` | 选档第 8 挡输出 |
| `RSEL_9` | 选档第 9 挡输出 |
| `RSEL_10` | 选档第 10 挡输出 |
| `RSEL_11` | 选档第 11 挡输出 |
| `RSEL_12` | 选档第 12 挡输出 |

`RED_FORCE_OUT` 和 `RED_SENSE_OUT` 只作为 J1 端子丝印/外部接线功能名，不要在原理图里建成独立网络。画原理图时，J1-2 和 J1-3 都直接贴 `RED_KELVIN` 网络标签。

## 电路连接拓扑图

```text
采样板 J2-1 WHITE  <-> J1-1 WHITE_OUT -> JP1-A1..A12 公共排

JP1-B1  -> RSEL_1  -> R1 100Ω   -> RED_KELVIN
JP1-B2  -> RSEL_2  -> R2 130Ω   -> RED_KELVIN
...
JP1-B12 -> RSEL_12 -> R12 154Ω   -> RED_KELVIN

RED_KELVIN -> J1-2, 丝印 RED_FORCE_OUT, 接采样板 RED_FORCE
RED_KELVIN -> J1-3, 丝印 RED_SENSE_OUT, 接采样板 RED_SENSE
```

JP1 用 2x12 排针实现选档：A 排 12 个脚全部短接到 `WHITE_OUT`，B 排 12 个脚分别接 `RSEL_1` 到 `RSEL_12`。使用时只插一个 2.54mm 短路帽，短接某一列的 A/B 两脚；严禁同时插两个短路帽。

J1-2 和 J1-3 是同一个 `RED_KELVIN` 电气网络，必须和所有电阻的红线公共端直接连通；`RED_FORCE_OUT` / `RED_SENSE_OUT` 只是端子丝印名称，不能作为独立网络名使用。

## 画图步骤

1. 先放 J1，J1-1 接 `WHITE_OUT`，J1-2/J1-3 都接 `RED_KELVIN`；端子丝印仍按 `WHITE_OUT / RED_FORCE_OUT / RED_SENSE_OUT` 顺序写。
2. 放 JP1 2x12 排针，A 排 12 个脚全部接 `WHITE_OUT`，B 排 12 个脚依次接 `RSEL_1` 到 `RSEL_12`。
3. 放 R1~R12；每个挡位都是单颗 0603 电阻，一端接对应 `RSEL_x`、另一端接 `RED_KELVIN`。
4. 用一个短而粗的 `RED_KELVIN` 汇接点同时接到所有电阻红端、J1-2 和 J1-3。
5. 放 TP1~TP4，测试点只接对应网络。
6. 在每个电阻旁边放温度和阻值丝印，不要只写 R1/R2。

## 外部接线表

| 模拟测试板 J1 | 接 PT100 采样板 J2 |
| --- | --- |
| J1-1 `WHITE_OUT` | J2-1 `WHITE` |
| J1-2 丝印 `RED_FORCE_OUT`，电气网 `RED_KELVIN` | J2-2 `RED_FORCE` |
| J1-3 丝印 `RED_SENSE_OUT`，电气网 `RED_KELVIN` | J2-3 `RED_SENSE` |

## PCB 注意事项

- JP1 放中间，R1~R12 围绕 JP1 放，JP1-Bx 到电阻的线越短越好。
- `WHITE_OUT` 只走到 JP1-A 排公共母线，不要绕到电阻公共端。
- `RED_KELVIN` 是所有电阻红端、J1-2、J1-3 的公共点，走线粗短，建议 20mil 或更宽。
- J1-2 和 J1-3 在测试板上就是同一个 `RED_KELVIN` 网络，分别对应外部采样板的 `RED_FORCE` 和 `RED_SENSE`。
- 每个挡位旁边都放丝印：挡位号、温度、电阻值。
- 如果实际采购阻值与标称不同，用四位半或六位半表实测，并把实测阻值写入测试记录和软件标定表。
- 如果演示必须要旋钮手感，改用 `2P6T 先断后合旋转开关 + SPDT 拨动开关`：SPDT 公共端接 `WHITE_OUT`，两端分别接 2P6T 的 A/B 公共端；2P6T-A 的 1~6 接 `RSEL_1..RSEL_6`，2P6T-B 的 1~6 接 `RSEL_7..RSEL_12`。
