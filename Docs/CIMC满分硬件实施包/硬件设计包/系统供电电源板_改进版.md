# 系统供电电源板_改进版

## 页面目标

完成一块独立双层 PCB，把赛题 `18V~36V DC` 输入转换为稳定 `5.00V/2A`，给 GD32F470 开发板 5V 供电点使用。本改进版是“稳分版/易调试版”：正常工作时让 GD30DC1354 按手册直接承受 `18V~36V` 输入，取消前级 P-MOS 线性限压闭环，降低发热、振荡和调试风险。

| 项目 | 内容 |
| --- | --- |
| 板名 | `系统供电电源` |
| 版本定位 | 改进版、稳分版、简化前级保护 |
| 输入 | `18V~36V DC`，典型 24V |
| 输出 | `5V_OUT = 5.00V/2A` |
| 核心芯片 | `GD30DC1354`，必须使用赛题指定 Buck |
| 保护目标 | 防反接、输入浪涌吸收、输入滤波、可选 EN 过压关断实验位 |
| 关键验收 | 18V/24V/36V 输入，空载和开发板负载输出均在 `4.85V~5.15V` |
| 丝印 | `系统供电电源 队伍编号 2026-05` |

说明：本版以 `Docs/GD30DC1354资料` 中 VIN 推荐工作范围 `4.5V~36V`、绝对最大 `38V` 的资料为依据。36V 是正常工作上限，不再通过 Q2 把芯片输入强行限制到 32V。

## 固定网络名

| 网络名 | 含义 |
| --- | --- |
| `VIN_IN` | 输入端子正极，18V~36V |
| `GND` | 输入、输出公共地 |
| `VIN_FUSED` | 自恢复保险丝后输入 |
| `VIN_REV` | 防反接 MOS 后、Buck 实际输入节点，直接接 GD30DC1354 VIN 和输入电容 |
| `REV_GATE` | 防反接 P-MOS 栅极 |
| `VIN_DIV` | 可选输入电压检测分压点，只用于 EN 过压关断实验位 |
| `EN` | GD30DC1354 使能脚，默认悬空使能，可选焊接下拉/过压关断 |
| `SW` | GD30DC1354 开关节点，只接 U1 SW、L1、C14、Snubber 预留位 |
| `BST` | GD30DC1354 自举节点 |
| `VOUT_REG` | DC-DC 输出滤波节点，电流测量跳线前 |
| `VOUT_5V` | 电流测量跳线后，真正输出到开发板 |
| `FB` | GD30DC1354 反馈节点 |

本改进版主方案取消以下旧版主网络：`VIN_BUCK`、`PASS_GATE`、`VCC_CTRL`、`VREF_2V495`、`CLAMP_FB`、`CLAMP_DRV`、`GATE_DRV`、`OVP_DIV`、`OVP_DRV`。如果想保留旧版保护电路，只能作为 DNP 实验位，不能串入正常主电流路径。

## 电路连接拓扑图

```text
输入主电流路径：
J1-1 VIN_IN -> F1 -> VIN_FUSED -> Q1 -> VIN_REV -> U1 VIN
J1-2 GND ---------------------------------------------> U1 GND

防反接：
Q1-D = VIN_FUSED
Q1-S = VIN_REV
Q1-G = REV_GATE
REV_GATE -> R1 -> GND
REV_GATE -> R2 -> VIN_REV
D1 跨接 VIN_REV 与 REV_GATE，钳位 Q1 的 Vgs

输入浪涌与滤波：
D2 从 VIN_REV 到 GND，吸收输入瞬态
C1/C2/C3/C4 从 VIN_REV 到 GND，靠近 U1 VIN 和 Q1 输出侧
R17+C13 为可选热插拔阻尼支路，串联后从 VIN_REV 到 GND
R18 从 VIN_REV 到 GND，作为断电放电电阻

可选 EN 关断实验位：
EN 默认悬空，使 U1 自动使能
R23 可选下拉到 GND，用于调试关断
R24/R25/Q2/R26 可选组成输入过压拉低 EN 的实验位，默认 DNP

Buck 主回路：
U1 VIN = VIN_REV
U1 SW -> SW -> L1 -> VOUT_REG
U1 BST -> BST -> C14 -> SW
VOUT_REG -> C16/C17/C18 -> GND

反馈和输出：
VOUT_REG -> R20 -> FB -> R21 -> GND
C19 并联在 VOUT_REG 与 FB 之间
VOUT_REG -> J2 I-MEAS -> VOUT_5V -> J3-1
J3-2 -> GND
VOUT_5V -> R22 -> LED2 -> GND
```

## 关键计算

```text
GD30DC1354 输入范围：
手册推荐工作范围：VIN = 4.5V~36V
绝对最大额定：VIN = -0.3V~38V
赛题要求：18V~36V 输入稳定输出 5V

结论：
36V 是正常工作上限，主方案不再设置 31.94V 线性限压。
防护重点放在防反接、输入 TVS、足够耐压电容、短粗输入回路和热插拔波形验证。
```

```text
输出反馈：
Vout = 0.6V * (1 + R20 / R21)
     = 0.6V * (1 + 110k / 15.0k)
     = 5.00V
```

```text
占空比估算：
D ≈ Vout / Vin

Vin = 18V: D ≈ 5 / 18 = 27.8%
Vin = 24V: D ≈ 5 / 24 = 20.8%
Vin = 36V: D ≈ 5 / 36 = 13.9%

结论：
18V~36V 范围内占空比都处于 Buck 正常工作区间。
高输入电压时占空比较低，PCB 上更要控制 SW 节点面积和输入高频回路。
```

```text
电感纹波电流估算：
Delta_IL = (Vin - Vout) * Vout / (Vin * Fsw * L)
Fsw = 500kHz, L = 15uH, Vout = 5V

Vin = 18V: Delta_IL ≈ 0.48A, Ipeak ≈ 2.24A
Vin = 24V: Delta_IL ≈ 0.53A, Ipeak ≈ 2.26A
Vin = 36V: Delta_IL ≈ 0.57A, Ipeak ≈ 2.29A

结论：
L1 选 15uH，Isat 7A、Irms 6.25A，裕量充足。
若换料，Isat 必须 >=4A，直流电阻越低越好。
```

```text
输入电流估算：
Pout = 5V * 2A = 10W
假设效率 80%~88%

Vin = 18V: Iin ≈ 10W / (18V * 0.80~0.88) ≈ 0.63A~0.69A
Vin = 24V: Iin ≈ 0.47A~0.52A
Vin = 36V: Iin ≈ 0.32A~0.35A

结论：
F1 选 60V、Ihold=1.5A、Itrip=3A，避免 18V 满载和启动浪涌误动作。
Q1 选 100V TO-252 P-MOS，主要校核导通电阻、浪涌和封装散热。
```

```text
输入电容耐压：
最高正常输入 36V，考虑电源波动和热插拔尖峰，输入电解与陶瓷电容统一选 100V。
TVS 不能在 36V 正常输入时长期导通，可选 SMBJ36A/SMBJ40A 后按实际热插拔波形确认。
若现场可能长期误接 48V，本板不是长期 48V 保护方案，应在文档中说明只做赛题 18V~36V 范围设计。
```

```text
输出电容：
C16/C17 = 22uF/25V 陶瓷，贴近 L1 输出端和 U1 GND 回路。
C18 = 100uF/10V 电解，提供低频储能。
输出额定 5V，10V 电解满足耐压；陶瓷选 25V 是为了降低直流偏压下容量衰减。
```

```text
可选 EN 关断实验位：
U1 EN 默认悬空使能，不接输入高压。
若需要演示过压保护，只允许通过高阻分压和小信号管把 EN 拉低。
该实验位默认 DNP，不作为比赛基础功能依赖。
```

## 画图步骤

1. 先画输入端：`J1 -> F1 -> Q1 -> VIN_REV`，并把 `R1/R2/D1/D2/C1` 放在 Q1 附近。
2. 画 U1 Buck 主回路：`U1/C14/L1/C16/C17/C18`，其中 U1 VIN 直接接 `VIN_REV`。
3. 在 `VIN_REV` 与 `GND` 之间放 `C2/C3/C4/R17+C13/R18`，输入陶瓷必须靠近 U1。
4. 画反馈：`R20/R21/C19`，只让 `FB` 连接这三个元件和 U1 FB 脚。
5. 画输出：`J2 I-MEAS` 串在 `VOUT_REG` 与 `VOUT_5V` 中间，再接 `J3/LED2/R22`。
6. 放可选 EN 位：`R23` 默认 DNP；`R24/R25/Q2/R26` 全部 DNP，只作实验位。
7. 放测试点：`TP_IN/TP_VIN/TP_SW/TP_FB/TP_5V/TP_GND/TP_EN`。

## PCB 注意事项

- `VIN_IN -> F1 -> Q1 -> VIN_REV -> U1 VIN` 主电流路径要短而宽，建议 60mil 以上或直接铺铜。
- `C2/C3/C4` 必须贴近 U1 VIN 和 GND，输入高频电流环路面积越小越好。
- `D2` 到 GND 的回流路径必须最短，旁边放 GND 过孔。
- `SW` 铜皮只保留 U1 SW 到 L1 的必要面积，远离 `FB`、输出端子、EN 分压和板边。
- `R20/R21/C19` 紧贴 U1 FB；`R20` 从输出电容正端 Kelvin 取样。
- 底层尽量完整铺 `GND`，不要在 U1 GND、输入电容地、输出电容地之间割裂。
- `J2 I-MEAS` 用额定 3A 以上短接帽或端子；PCB 丝印写 `I-MEAS SHORT NORMAL`。
- Q1 虽然不是主要发热点，也要保留足够铜皮；36V 满载记录 Q1/U1/L1 温升。
- 可选 EN 过压关断实验位放在控制区，不要靠近 `SW` 和电感；首版不焊时不能影响 EN 悬空使能。

## 与当前版本对比需要改哪些地方

| 类别 | 当前版本 | 改进版需要改动 |
| --- | --- | --- |
| 主电流路径 | `VIN_IN -> F1 -> Q1 -> VIN_REV -> Q2 -> VIN_BUCK -> U1 VIN` | 改为 `VIN_IN -> F1 -> Q1 -> VIN_REV -> U1 VIN`，删除主路径上的 Q2 |
| Buck 输入节点 | `VIN_BUCK` 是 Q2 后的限压节点 | 取消 `VIN_BUCK` 主网络，统一使用 `VIN_REV` 作为 U1 VIN 和输入电容节点 |
| 36V 策略 | 36V 输入时把 U1 VIN 限到约 31.94V | 36V 作为 GD30DC1354 正常工作上限直接校核 |
| 线性限压 | Q2/U3A/TL431/Q3 构成闭环限压 | 删除该闭环；不再让 P-MOS 在线性区承担正常工况压降 |
| 过压关断 | U3B/Q4 关断 Q2，并点亮 OVP_FAULT | 改为可选 EN 拉低实验位，默认 DNP；基础评分不依赖该功能 |
| 控制电源 | `R7/D4` 产生 `VCC_CTRL`，TL431 产生 `VREF_2V495` | 主方案删除 `VCC_CTRL` 和 `VREF_2V495` |
| 输入 TVS | D2 在 `VIN_REV`，D5 在 `VIN_BUCK` | 保留一个主输入 TVS D2；D5 芯片侧 TVS可删除或并入 D2 选型验证 |
| 输入电容 | C1 在 `VIN_REV`，C9~C12 在 `VIN_BUCK` | 把输入储能和高频旁路统一放在 `VIN_REV`，靠近 U1 VIN |
| 热插拔阻尼 | R17+C13 接 `VIN_BUCK` | 改接 `VIN_REV`，仍为串联 RC 到地，可按波形决定是否焊接 |
| 发热点 | Q2 是 36V 满载主要发热点之一 | 主要热源变为 U1、L1、Q1 导通损耗；不再有 Q2 线性压降热源 |
| 需要删除的器件 | Q2、Q3、Q4、U2、U3、R3~R16、C3~C8、D3~D5 等限压/比较链 | 原理图主方案删除；若想留实验位，全部标 DNP 且不得串主电流 |
| 需要保留的器件 | J1/F1/Q1/D1/D2、U1/L1/C14/C16~C19/R20/R21、J2/J3/LED2 | 继续保留，并按新版网络重新连接 |
| 测试记录 | 记录 `VIN_BUCK≈31.8V~32.2V` 和 Q2 温升 | 改为记录 `VIN_REV≈输入电压`、U1/L1/Q1 温升、SW 振铃和输出纹波 |
| 答辩说法 | “不让芯片长期顶在 36V 上限” | “按指定芯片手册 36V 正常工作设计，前级只做必要保护，减少线性限压风险” |

### 从旧版原理图改到新版的操作清单

1. 删除主电流中的 Q2，把 Q1 后的 `VIN_REV` 直接连接到 U1 VIN。
2. 删除或 DNP 旧版 `PASS_GATE/CLAMP_FB/CLAMP_DRV/GATE_DRV/OVP_DIV/OVP_DRV/VCC_CTRL/VREF_2V495` 相关电路。
3. 把旧版 `VIN_BUCK` 上的输入电容、放电电阻、热插拔阻尼改接到 `VIN_REV`。
4. 删除旧版 `D5 VIN_BUCK TVS`，或把保护策略合并为 `VIN_REV` 主输入 TVS。
5. 保留 Buck 主电路、反馈网络、输出电流测量接口和输出 LED，并核对网络名。
6. 更新 PCB：Q1 到 U1 VIN 的路径更短更宽，U1 输入电容必须贴近芯片；原 Q2/LM358/TL431 区域释放出来给输入电容、地过孔和散热铜皮。
7. 更新测试记录模板：不再要求 `VIN_BUCK≈31.94V`，改为验证 18V/24V/36V 输入下输出合格、U1/L1/Q1 温升合格。
