# 傻瓜式 EDA 连线表

这份文档现在只做索引和使用说明，不再重复维护一份三块板混在一起的长表。真正画原理图时，请直接打开对应板子的逐元件文档；每一份文档都已经按“位号 -> 型号/立创编号 -> 引脚/网络连接 -> 参数 -> 封装 -> 备注”的格式写好。

## 先读哪一份

| 你要画的板 | 直接打开 |
| --- | --- |
| 18V~36V 转 5V/2A 电源板，含防反接、限压、过压关断和热插拔阻尼 | `系统供电电源板.md` |
| PT100 温度采样和 GD30AD3344 ADC 板 | `PT100温度采样板.md` |
| 12 挡精密电阻模拟测试板 | `模拟测试板.md` |

PT100 采样板当前采用 `REF5025 外部基准 + 1.25V 激励 + 1mA 低边恒流 + INA333 仪表放大 + AIN1/AIN2 三线补偿监测` 路线；画图时以 `PT100温度采样板.md` 的逐元件表为唯一连线依据。

## EDA 画图方法

1. 每块板单独建一个工程，不要把三块板画在同一张原理图里。
2. 先照“固定网络名”建立 NetLabel。
3. 再照“器件与连接表”逐个放元件。
4. 每个元件只看自己那一行：把表格里写的引脚接到对应网络。
5. 同名网络在 EDA 里就是电气连接，不需要用长线全部拉在一起。
6. 原理图画完后用高亮网络检查：同名网络必须全亮，不同网络不能误亮。

## 全局检查

| 板子 | 必查项 |
| --- | --- |
| 系统供电电源板 | 主路径必须是 `VIN_IN -> F1 -> VIN_FUSED -> Q1 -> VIN_REV -> Q2 -> VIN_BUCK -> U1 VIN`；`SW` 只接 U1 SW、L1、C14、Snubber 预留位；`FB` 只接 U1 FB、R20、R21、C19；J2 是 `I-MEAS` 串联跳线 |
| PT100 温度采样板 | `AGND/DGND` 只通过 NT1 单点连接；U6 AIN0 接 INA333 输出，AIN1 接 `RED_SENSE_MON`，AIN2 接 `VFORCE_MON`，AIN3 只接外部基准；`RED_FORCE` 和 `RED_SENSE` 不在采样板上短接 |
| 模拟测试板 | JP1 选档排针测试时只能插 1 个短路帽；任意挡位只接入一个单颗电阻或一个串联组合；所有挡位末端、J1-2、J1-3 都直接接 `RED_KELVIN`；`RED_FORCE_OUT` 和 `RED_SENSE_OUT` 只作为端子丝印/外接功能名 |

## 下单前最后确认

- 队伍编号和设计年月在三块板顶层丝印里替换成实际信息。
- 立创商城库存会变化；如果某个阻值或连接器缺货，只能换同参数、同封装或更高规格料，并把替代料号同步写回对应板子的表格。
- 电源板若替换 Q1/Q2，必须保持 `P-MOS、Vds>=100V、TO-252 或更强散热封装`，并重新核对 D/S/G 脚序。
- GD30DC1354 和 GD30AD3344 按比赛样片或原厂渠道获取，不用随便替换。
- 出板前导出原理图 PDF、BOM、Gerber、坐标文件，并保存 ERC/DRC 截图。
