# 系统供电电源板 PCB 绘制与设计原理手册

## 1. 手册目标

本手册用于指导绘制 `系统供电电源板` 的原理图复核、双层 PCB 布局布线、打板前检查和首次上电测试。目标板把 `18V~36V DC` 输入转换为稳定 `5.00V/2A` 输出，给 GD32F470 开发板和后级采样板供电。

本手册适合初学者照做，也适合方案书和答辩时解释设计依据。绘图时以 `系统供电电源板.md` 的网络名、元件表和计算为准。

## 2. 总体电路结构

整板可以按 7 个功能块理解：

| 功能块 | 主要器件 | 作用 |
| --- | --- | --- |
| 输入端和保险 | `J1/F1` | 接入 18V~36V，输入严重故障时限流保护 |
| 防反接 | `Q1/R1/R2/D1` | 输入接反时阻断电流，正接时低损耗导通 |
| 前级浪涌吸收 | `D2/C1/C2` | 吸收输入线缆和热插拔产生的尖峰 |
| Buck 输入限压/关断 | `Q2/Q3/Q4/U3/R9/R10/R11/R12` | 36V 正常工作时把 `VIN_BUCK` 限到约 31.94V；输入过高时关断 |
| 控制电源和基准 | `R7/D4/U2/R8/C3/C4/C5` | 产生约 12V 控制电源和 2.495V 参考 |
| Buck 主电源 | `U1/L1/C9~C19/R20/R21` | GD30DC1354 降压输出 5V/2A |
| 输出和测流 | `J2/J3/R22/LED2` | 输出 5V，并提供串表测电流跳线 |

主电流路径必须保持一致：

```text
J1-正极 -> VIN_IN -> F1 -> VIN_FUSED -> Q1 -> VIN_REV -> Q2 -> VIN_BUCK -> U1 VIN
J1-负极 -> GND
U1 SW -> L1 -> VOUT_REG -> J2 -> VOUT_5V -> J3-正极
J3-负极 -> GND
```

`VIN_IN`、`VIN_REV`、`VIN_BUCK`、`SW`、`VOUT_REG`、`VOUT_5V` 是 PCB 上最重要的几个网络。画板时必须先保证这些网络的路径短、宽、清楚。

## 3. 电路设计原理

### 3.1 输入保险 F1

`F1` 是自恢复保险丝，串在 `VIN_IN` 和 `VIN_FUSED` 之间。正常 18V 满载时输入电流约：

```text
Pin ≈ 10W / 0.8~0.85 ≈ 11.8W~12.5W
Iin ≈ 12W / 18V ≈ 0.67A
```

所以 `Ihold=1.5A` 的 PTC 不容易在正常工作和启动浪涌下误动作。输入短路或严重故障时，它会升温变高阻，限制持续故障电流。

### 3.2 P-MOS 防反接 Q1

`Q1` 是高边 P-MOS 防反接管：

```text
Q1-D = VIN_FUSED
Q1-S = VIN_REV
Q1-G = REV_GATE
REV_GATE -> R1 -> GND
REV_GATE -> R2 -> VIN_REV
D1: K=VIN_REV, A=REV_GATE
```

正接时，`R1` 把 Gate 拉低，P-MOS 导通，电流从输入流向 `VIN_REV`。`D1` 是 12V 稳压管，用来限制 `Vgs`，防止 24V/36V 输入时 Gate-Source 过压。

反接时，P-MOS 的体二极管方向被阻断，`R2` 让 Gate 和 Source 跟随，Q1 关闭。PCB 上必须核对所选 TO-252 P-MOS 的 `D/S/G` 实际脚序，不要只按符号外形想当然连接。

### 3.3 前级 TVS 和输入电容

`D2` 是 `VIN_REV` 到 `GND` 的单向 TVS，用来吸收输入线缆、热插拔和外部电源瞬态带来的高压尖峰。`C1` 提供低频储能，`C2` 提供高频旁路。

布局要求：

- `D2` 靠近输入保护链路，回到 GND 的路径必须短。
- `C1/C2` 放在 `Q1/Q2` 附近，减少前级输入阻抗。
- TVS 到地的回流不要绕远路，旁边放 GND 过孔。

### 3.4 Q2 线性限压和关断

`Q2` 是高边 P-MOS，通过控制 Gate 把 `VIN_BUCK` 限在安全范围：

```text
Q2-S = VIN_REV
Q2-D = VIN_BUCK
Q2-G = PASS_GATE
PASS_GATE -> R3 -> VIN_REV
PASS_GATE -> R4 -> Q3-C
D3: K=VIN_REV, A=PASS_GATE
```

`R3` 默认把 Gate 拉到 Source，Q2 关闭。`Q3` 导通时把 `PASS_GATE` 往低处拉，Q2 导通。`D3` 限制 Q2 的 `Vgs`，避免 Gate 被拉得过低。

36V 输入满载时，Q2 会工作在线性区，承担一部分压降和发热。按目标限压 `31.94V` 估算：

```text
Pout = 5V * 2A = 10W
假设 Buck 效率 85%，Pin ≈ 10W / 0.85 = 11.76W
Iin ≈ 11.76W / 31.94V = 0.37A
P_Q2 ≈ (36V - 31.94V) * 0.37A ≈ 1.5W
```

因此 `Q2` 必须使用 TO-252 或散热能力更强的封装，并用大面积铜皮和过孔阵列导热。

### 3.5 控制电源 VCC_CTRL 和 TL431 基准

`R7/D4` 从 `VIN_REV` 产生约 12V 的 `VCC_CTRL`：

```text
VIN_REV -> R7 3.3k -> VCC_CTRL
VCC_CTRL -> D4 12V Zener -> GND
C3/C4: VCC_CTRL 去耦
```

`U2 TL431` 和 `R8` 产生 `VREF_2V495`：

```text
VCC_CTRL -> R8 10k -> VREF_2V495
TL431 REF/K -> VREF_2V495
TL431 A -> GND
C5 -> GND
```

这个 2.495V 参考同时供限压环路和过压比较使用。画图时必须按所选 TL431 的封装脚序核对 `REF/K/A`，尤其是 SOT-23 封装，不同库符号容易看错。

### 3.6 VIN_BUCK 限压环路

限压分压应为：

```text
VIN_BUCK -> R9A 100k -> R9B 18k -> CLAMP_FB -> R10 10k -> GND
```

目标限压：

```text
V_BUCK_LIMIT = 2.495V * (1 + (100k + 18k) / 10k)
             = 31.94V
```

`U3A` 比较 `CLAMP_FB` 和 `VREF_2V495`，通过 `CLAMP_DRV -> R5 -> GATE_DRV -> Q3` 调节 Q2 的 Gate。`C6` 用于反馈滤波，`C7` 用于环路补偿，降低 Q2 在线性限压时振荡的风险。

注意：`CLAMP_FB` 是高阻检测点，不能靠近 `SW`、电感、输入 TVS 大电流回路和输出端子。

### 3.7 输入过压关断

过压分压应为：

```text
VIN_REV -> R11A 120k -> R11B 18k -> OVP_DIV -> R12 10k -> GND
```

过压阈值：

```text
V_OVP = 2.495V * (1 + (120k + 18k) / 10k)
      = 36.93V
```

当输入超过约 36.9V 时，`U3B` 输出 `OVP_DRV`，点亮 `LED1`，并通过 `R14/Q4` 拉低 `GATE_DRV`。`GATE_DRV` 被拉低后，Q3 关闭，`PASS_GATE` 被 `R3` 拉回 `VIN_REV`，Q2 关断，Buck 输入被切断。

`R13` 从 `OVP_DRV` 回到 `OVP_DIV`，形成轻微回差，减少阈值附近反复闪断。

### 3.8 R17+C13 热插拔阻尼

`R17+C13` 是串联到地的阻尼支路：

```text
VIN_BUCK -> R17 2.2R -> C13 1uF -> GND
```

它不是普通输入电容。上电瞬间，`C13` 会通过 `R17` 充电；充满后直流开路，不再产生持续电流。它的主要作用是吸收长线供电、热插拔和输入电容造成的高频振铃。

时间常数约为：

```text
tau = R * C = 2.2R * 1uF = 2.2us
```

如果实测 `VIN_BUCK` 热插拔过冲较大，可以保留该支路；如果波形已经很好，也可以把 `R17` 或 `C13` 做成可选位。

### 3.9 R18 放电电阻

`R18` 是 `VIN_BUCK` 到地的泄放电阻：

```text
VIN_BUCK -> R18 10k -> GND
```

它不在主电流路径里，不会像串联电阻那样分压。它只是给 `C9/C10/C11/C12` 提供断电后的放电路径。

在 `VIN_BUCK≈32V` 时：

```text
I_R18 = 32V / 10k = 3.2mA
P_R18 = 32V * 3.2mA = 0.102W
```

所以建议使用 `1206 0.25W` 或更高规格。若希望降低常耗，可以改为 `22k~47k`，但放电速度会变慢。

### 3.10 GD30DC1354 Buck 主电路

`U1` 的关键连接：

```text
U1-1 GND = GND
U1-2 SW  = SW
U1-3 VIN = VIN_BUCK
U1-4 FB  = FB
U1-5 EN  = EN
U1-6 BST = BST
```

`EN` 悬空默认使能，不要接 24V/36V。`FB` 只能接反馈网络，不要接高压。

反馈分压：

```text
VOUT_REG -> R20 110k -> FB -> R21 15k -> GND
C19 75pF 并联在 R20 两端
```

输出电压：

```text
Vout = 0.6V * (1 + 110k / 15k) = 5.00V
```

`C14` 是自举电容，必须贴近 `BST/SW`。`L1` 从 `SW` 接到 `VOUT_REG`。`C16/C17/C18` 是输出滤波电容，应靠近电感输出端和 U1 地回流。

### 3.11 J2 输出测流跳线

`J2` 串在 `VOUT_REG` 和 `VOUT_5V` 之间：

```text
VOUT_REG -> J2 -> VOUT_5V -> J3
```

正常使用时短接 `J2`。需要测电流时，取下短接帽，把万用表电流档串入 `J2` 两端。J2 和相关走线必须按 2A 以上连续电流设计，建议额定不低于 3A。

## 4. 原理图绘制和复核步骤

### 4.1 先固定网络名

在嘉立创 EDA 中先建立并统一使用下列网络名：

```text
VIN_IN
VIN_FUSED
VIN_REV
VIN_BUCK
REV_GATE
PASS_GATE
VCC_CTRL
VREF_2V495
CLAMP_FB
CLAMP_DRV
GATE_DRV
OVP_DIV
OVP_DRV
SW
BST
VOUT_REG
VOUT_5V
FB
EN
GND
```

同名网络就是电气连接。不要为了看起来连在一起而画很长的线，长线反而容易误连。

### 4.2 按功能块画原理图

推荐顺序：

1. 画 `J1/F1/Q1`，形成 `VIN_IN -> VIN_FUSED -> VIN_REV`。
2. 画 `Q2/Q3/Q4`，形成 `VIN_REV -> Q2 -> VIN_BUCK`。
3. 画 `R7/D4/U2/R8`，得到 `VCC_CTRL` 和 `VREF_2V495`。
4. 画 `U3A` 限压环路和 `U3B` 过压关断。
5. 画 `D5/C9/C10/C11/C12/R17/C13/R18`，完成 Buck 输入侧。
6. 画 `U1/C14/L1/C16/C17/C18/R20/R21/C19`。
7. 画 `J2/J3/LED2/R22`。
8. 补 `R23/TP1~TP8` 测试点。

### 4.3 ERC 前人工核对

ERC 只能发现一部分错误，下面这些必须人工看：

| 项目 | 正确要求 |
| --- | --- |
| Q1 | `D=VIN_FUSED, S=VIN_REV, G=REV_GATE` |
| Q2 | `S=VIN_REV, D=VIN_BUCK, G=PASS_GATE` |
| U1 | `VIN` 只接 `VIN_BUCK`，`SW` 只接电感/自举/snubber |
| FB | 只接 `U1 FB/R20/R21/C19` |
| EN | 默认悬空，只接测试点和可选下拉，不接输入高压 |
| CLAMP_FB | `R9A+R9B=118k`，下臂 `R10=10k` |
| OVP_DIV | `R11A+R11B=138k`，下臂 `R12=10k` |
| J2 | 串在 `VOUT_REG` 和 `VOUT_5V` 中间 |
| TVS | 单向 TVS 极性正确，阴极接正电源，阳极接 GND |

## 5. PCB 绘制总体原则

本板建议使用双层 PCB：

```text
Top Layer: 主要器件、功率走线、局部铺铜
Bottom Layer: 尽量完整 GND 平面，少切割、少跨缝
```

核心原则：

- 功率电流先走最短、最宽路径。
- `SW` 节点面积要小，不要为了“粗”而铺很大。
- 输入电容、输出电容和 U1 的地回路要短。
- `FB/CLAMP_FB/OVP_DIV` 远离 `SW`、电感和高 dv/dt 节点。
- Q2 和 U1 的散热优先通过铜皮和过孔解决。
- 所有端子、测试点、丝印必须便于接线和调试。

## 6. 器件摆放步骤

### 6.1 先放接口和板框

1. 先确定板框尺寸、安装孔和端子方向。
2. `J1` 放在输入侧边缘，丝印清楚写 `VIN+`、`VIN-`。
3. `J3` 放在输出侧边缘，丝印清楚写 `5V`、`GND`。
4. `J2` 放在输出路径上，靠近 `J3`，丝印写 `I-MEAS` 和 `SHORT NORMAL`。
5. 高压输入区和 5V 输出区在视觉上分开，避免接线时混淆。

### 6.2 摆放输入保护链

按电流流动方向一字排开：

```text
J1 -> F1 -> Q1 -> Q2 -> VIN_BUCK 输入电容 -> U1
```

要求：

- `F1` 靠近 J1。
- `Q1` 靠近 F1。
- `Q2` 靠近 Q1 和 Buck 输入电容。
- `D2` 靠近 `VIN_REV` 前级，GND 回路短。
- `D5` 靠近 `VIN_BUCK` 和 U1 输入电容，GND 回路短。

### 6.3 摆放 Buck 功率级

Buck 功率级按这个局部闭环摆放：

```text
U1 VIN -> U1 内部开关 -> SW -> L1 -> VOUT_REG -> 输出电容 -> GND -> U1 GND
```

要求：

- `C10/C11/C12` 紧贴 U1 `VIN/GND`。
- `C14` 紧贴 U1 `BST/SW`。
- `L1` 紧贴 U1 `SW`，但不要让电感压住反馈网络。
- `C16/C17/C18` 紧贴 L1 输出端。
- `R20/R21/C19` 紧贴 U1 FB 脚。

### 6.4 摆放控制小信号

`U3/TL431/分压电阻` 远离电感和 SW 节点。推荐放在功率链路侧边，形成干净的控制区。

要求：

- `R9A/R9B/R10/C6/C7` 靠近 U3A，`CLAMP_FB` 走线短。
- `R11A/R11B/R12/C8/R13` 靠近 U3B，`OVP_DIV` 走线短。
- `R5/R6/Q3/Q4/R14/R15` 靠近 Q2 Gate 控制区域。
- 控制区地尽量回到底层完整 GND，不跨过 SW 铜皮下方。

### 6.5 摆放测试点

建议保留以下测试点：

| 测试点 | 网络 | 用途 |
| --- | --- | --- |
| TP_IN | `VIN_IN` | 输入端电压 |
| TP_REV | `VIN_REV` | 防反接后电压 |
| TP_BUCK | `VIN_BUCK` | Buck 实际输入和限压测试 |
| TP_SW | `SW` | 示波器短地弹簧观察开关波形 |
| TP_FB | `FB` | 反馈电压，目标约 0.6V |
| TP_5V | `VOUT_5V` | 输出电压 |
| TP_GND | `GND` | 万用表/示波器地 |
| TP_EN | `EN` | 调试使能 |

`TP_SW` 必须小，不要做成很大的环形测试点。大测试点会增加 SW 寄生电容和 EMI。

## 7. 布线和铺铜规则

### 7.1 主电流路径

下面这些网络尽量用铺铜或宽线：

```text
VIN_IN
VIN_FUSED
VIN_REV
VIN_BUCK
VOUT_REG
VOUT_5V
GND 主回流
```

建议：

- 输入主路径建议 60mil 以上，空间允许时直接铺铜。
- 5V/2A 输出路径建议 80mil 以上或铺铜。
- 不要用细线穿过 F1、Q1、Q2、J2、J3 之间的主电流路径。
- 过孔承载电流有限，功率路径换层时要并多个过孔。

### 7.2 SW 节点

`SW` 是整板最吵的节点，只允许连接：

```text
U1 SW
L1 输入端
C14 到 BST
R19/C15 snubber 预留位
TP_SW 小测试点
```

布局要求：

- `SW` 铜皮只保留必要面积。
- 不要让 `SW` 在底层大面积铺开。
- 不要让 `SW` 从 `FB/CLAMP_FB/OVP_DIV` 下方经过。
- 不要把输出端子、控制分压、电压基准放在电感旁边。

### 7.3 输入电容回路

U1 的输入高频电流主要在这个回路中流动：

```text
C10/C11/C12 正极 -> U1 VIN -> U1 SW/GND 内部回路 -> U1 GND -> C10/C11/C12 负极
```

要求：

- 输入陶瓷电容必须离 U1 近。
- 电容负极到 U1 GND 的路径要短而宽。
- 底层 GND 在 U1 和输入电容下面保持完整。

### 7.4 输出电容回路

输出电流从 L1 到输出电容，再回到 GND。要求：

- `C16/C17/C18` 靠近 L1 输出端。
- 输出电容 GND 到 U1 GND 的回流路径要完整。
- `R20` 的上端从输出电容正端 Kelvin 取样，不要从 J3 远端随便拉。

### 7.5 FB 反馈网络

FB 网络决定输出电压稳定性。要求：

- `R20/R21/C19` 紧贴 U1 FB。
- `FB` 走线短，不穿过电感、SW、输入 TVS 附近。
- `R21` 下端回到干净 GND，不要接到大电流回流线上。
- `C19` 和 `R20` 并联关系要清楚，不能接错到 GND。

### 7.6 Q2 散热

Q2 是 36V 满载时的重点发热点。要求：

- TO-252 漏极/散热焊盘连接大面积顶层铜皮。
- 底层同区域铺铜，并用过孔阵列连接导热。
- Q2 周围不要放怕热的精密分压电阻。
- 首版必须记录 36V、2A 短时满载时 Q2 温升。

### 7.7 TVS 回流

`D2/D5` 的价值取决于回流路径是否短。要求：

- TVS 到 GND 的线越短越好。
- TVS 旁边放多个 GND 过孔。
- 不要让 TVS 电流穿过控制电路地再回电源负极。

### 7.8 底层 GND

底层优先做完整 GND 平面。要求：

- 不要在 U1、输入电容、输出电容之间割裂 GND。
- 小信号可以短距离换层，但不要切开高频回流路径。
- 顶层有大电流路径时，底层对应区域尽量保持 GND 参考面。

## 8. 丝印和可制造性

丝印必须服务调试和防接错：

| 位置 | 丝印建议 |
| --- | --- |
| J1 | `VIN+`、`VIN-`、`18V-36V DC` |
| J3 | `5V_OUT`、`GND` |
| J2 | `I-MEAS`、`SHORT NORMAL` |
| TP3 | `TP_BUCK` |
| LED1 | `OVP_FAULT` |
| LED2 | `5V_OK` |
| 板名 | `系统供电电源 队伍编号 2026-05` |

注意：

- 丝印不要压焊盘。
- 极性器件必须有方向标识，例如电解电容、TVS、LED、端子正负。

## 9. 当前 v2 图纸必须整改项

根据 `供电板v2.pdf` 当前版本，打板前必须处理以下问题。

### 9.1 RA9/RB9 阻值错误

当前图纸中：

```text
RA9 = 120k
RB9 = 2k
R10 = 10k
```

这样限压点为：

```text
V = 2.495V * (1 + (120k + 2k) / 10k)
  = 32.93V
```

这与设计目标 `31.94V` 不一致。应改为：

```text
RA9 = 100k
RB9 = 18k
R10 = 10k
```

目标：

```text
V = 2.495V * (1 + (100k + 18k) / 10k)
  = 31.94V
```

### 9.2 SW1 不建议串主电流路径

当前图纸中 `SW1` 看起来串在 `VIN_REV` 主输入路径上。普通小拨动开关不适合承受 18V~36V 供电、启动浪涌和满载输入电流。

建议二选一：

1. 删除 `SW1`，用铜线/0R/直接网络连接主电流路径。
2. 如果必须保留电源开关，换成额定电压、额定直流电流、浪涌能力足够的电源开关。

不建议把小信号拨动开关直接串在主电流路径中。

### 9.3 J1/J3 针脚编号和文档要统一

当前图纸的端子针脚编号与文档描述存在不一致风险。必须在原理图、PCB 丝印、接线表中统一：

```text
J1: VIN+ / GND
J3: 5V_OUT / GND
```

最终以 PCB 丝印和实际端子方向为准，打板前用 3D 视图和连通高亮确认。

### 9.4 补齐 R23 和测试点

建议补齐：

```text
R23: EN -> GND, 100k, DNP
TP_IN / TP_REV / TP_BUCK / TP_SW / TP_FB / TP_5V / TP_GND / TP_EN
```

没有测试点时，后续验证限压、过压关断、FB 电压和 SW 波形会非常不方便。

### 9.5 位号和封装命名统一

当前图纸中电感位号是 `L2`，文档中是 `L1`。建议统一为 `L1`，避免 BOM、贴片坐标和方案书对不上。

文档中输入/输出端子为 3.5mm，当前图纸显示为 5.08mm。两者都可以用，但必须统一 BOM、封装、外壳空间和接线表。

## 11. 上电调试流程

### 11.1 上电前

1. 万用表蜂鸣档检查 `VIN_IN` 到 `GND` 是否短路。
2. 检查 `VOUT_5V` 到 `GND` 是否短路。
3. 检查 Q1/Q2 方向、TVS 方向、电解电容方向。
4. 暂不接开发板，先空载测试。
5. 电源限流设置为 `100mA~200mA`，从低压开始上电。

### 11.2 18V 首次上电

测试点：

```text
VIN_IN ≈ 18V
VIN_REV ≈ 18V
VIN_BUCK ≈ 18V
VOUT_5V ≈ 5.00V
FB ≈ 0.60V
```

若电流异常升高、5V 不出、U1 或 Q2 发热，立即断电检查。

### 11.3 24V 正常测试

确认：

- `VOUT_5V` 在 `4.85V~5.15V`。
- `OVP_FAULT` 不亮。
- Q2、U1、L1 无异常升温。
- J2 短接状态可靠。

### 11.4 36V 限压测试

目标：

```text
VIN_BUCK ≈ 31.8V~32.2V
VOUT_5V ≈ 5.00V
```

用示波器观察 `TP_BUCK` 热插拔波形，峰值不应明显超过芯片安全范围。若 `VIN_BUCK` 接近 36V，优先检查 `RA9/RB9/R10`、U3A、Q3、Q2 Gate 控制。

### 11.5 过压关断测试

电源限流设置为 `100mA~200mA`，缓慢升压。目标现象：

```text
输入约 36.7V~37.2V 时关断
OVP_FAULT 红灯亮
VIN_BUCK 下降
VOUT_5V 关闭或明显下降
输入降回 36V 后恢复
```

若过压不关断，检查 `RA11/RB11/R12`、U3B、Q4、`GATE_DRV`、`PASS_GATE`。

### 11.6 负载和温升测试

按顺序测试：

| 输入 | 负载 | 重点 |
| --- | --- | --- |
| 18V | 空载 | 启动是否正常 |
| 18V | 开发板负载 | 5V 是否稳定 |
| 24V | 开发板负载 | 常规工作点 |
| 36V | 开发板负载 | 限压是否工作 |
| 36V | 1A 电子负载 | Q2/U1/L1 温升 |
| 36V | 2A 短时负载 | 满载能力和保护余量 |

36V、2A 满载时必须记录 `Q2/U1/L1/F1` 温升。如果 Q2 温升过高，优先加大散热铜皮、增加过孔、优化限压策略或降低长时间满载要求。

## 12. 常见错误和排查

| 现象 | 优先检查 |
| --- | --- |
| 5V 完全不输出 | EN 是否悬空、VIN_BUCK 是否到 U1、U1 GND 是否可靠 |
| 输出电压不对 | R20/R21 阻值、FB 是否被干扰、C19 是否接错 |
| 36V 时 VIN_BUCK 不限压 | RA9/RB9/R10、U3A 输入极性、Q3、Q2 Gate |
| 过压不关断 | RA11/RB11/R12、U3B、Q4、GATE_DRV |
| Q2 很烫 | 限压压差、负载电流、散热铜皮、SW1 是否串主电流 |
| SW 波形振铃大 | U1 输入电容距离、SW 铜皮、R19/C15 snubber、R17/C13 |
| 空载输出波动 | FB 布线、输出电容、PFM 模式、示波器测量方法 |
| 接线容易接反 | 端子丝印、针脚编号、3D 视图方向 |

## 13. 最小合格标准

打板前至少满足：

- 原理图已修正 `RA9=100k`、`RB9=18k`。
- 主电流路径没有普通小拨动开关串联，或开关额定值已证明足够。
- J1/J3 正负端子在原理图、PCB 和丝印中完全一致。
- U1 周围输入电容、自举电容、输出电容和反馈网络布局符合手册要求。
- `SW` 面积受控，`FB/CLAMP_FB/OVP_DIV` 远离开关节点。
- Q2 有明确散热设计。
- `TP_BUCK/TP_FB/TP_5V/TP_GND` 等关键测试点齐全。
- DRC/ERC 无未处理错误。

首次上电至少满足：

- 18V/24V/36V 空载输出在 `4.85V~5.15V`。
- 36V 输入时 `VIN_BUCK` 约 `31.8V~32.2V`。
- 过压约 `36.7V~37.2V` 关断，`OVP_FAULT` 点亮。
- 开发板负载下 5V 稳定。
- 36V 满载短时测试记录 Q2、U1、L1 温升。
