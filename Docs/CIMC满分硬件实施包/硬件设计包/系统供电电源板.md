# 系统供电电源板

## 页面目标

完成一块独立双层 PCB，把赛题 `18V~36V DC` 输入转换为稳定 `5.00V/2A`，给 GD32F470 开发板 5V 供电点使用。本版采用低成本耐造输入保护：防反接、前级浪涌吸收、P-MOS 线性限压、超过赛题上限过压关断、热插拔阻尼、故障指示和电流测量接口。

| 项目 | 内容 |
| --- | --- |
| 板名 | `系统供电电源` |
| 输入 | `18V~36V DC`，典型 24V |
| 输出 | `5V_OUT = 5.00V/2A` |
| 核心芯片 | `GD30DC1354`，必须使用赛题指定 Buck |
| 保护目标 | 36V 输入正常工作；Buck 实际输入 `VIN_BUCK` 限制在约 `31.9V~32.0V`；输入超过约 `36.9V` 自动关断 |
| 关键验收 | 18V/24V/36V 输入，空载和开发板负载输出均在 `4.85V~5.15V` |
| 丝印 | `系统供电电源 队伍编号 2026-05` |

## 固定网络名

| 网络名 | 含义 |
| --- | --- |
| `VIN_IN` | 输入端子正极，18V~36V |
| `GND` | 输入、输出公共地 |
| `VIN_FUSED` | 自恢复保险丝后输入 |
| `VIN_REV` | 防反接 MOS 后、线性限压 MOS 前的输入 |
| `VIN_BUCK` | 限压/关断/滤波后的 Buck 实际输入，只接 GD30DC1354 VIN 和输入电容 |
| `REV_GATE` | 防反接 P-MOS 栅极 |
| `PASS_GATE` | 线性限压 P-MOS 栅极 |
| `VCC_CTRL` | 输入保护控制电路约 12V 本地电源 |
| `VREF_2V495` | TL431 产生的 2.495V 控制参考 |
| `CLAMP_FB` | `VIN_BUCK` 限压反馈分压点 |
| `CLAMP_DRV` | LM358A 限压环路输出 |
| `GATE_DRV` | Q3 基极驱动节点，过压时被拉低 |
| `OVP_DIV` | `VIN_REV` 过压关断分压点 |
| `OVP_DRV` | LM358B 过压比较输出 |
| `SW` | GD30DC1354 开关节点，只接 U1 SW、L1、C14、Snubber 预留位 |
| `BST` | GD30DC1354 自举节点 |
| `VOUT_REG` | DC-DC 输出滤波节点，电流测量跳线前 |
| `VOUT_5V` | 电流测量跳线后，真正输出到开发板 |
| `FB` | GD30DC1354 反馈节点 |
| `EN` | GD30DC1354 使能测试点，默认悬空 |

## 电路连接拓扑图

```text
输入主电流路径：
J1-1 VIN_IN -> F1 -> VIN_FUSED -> Q1 -> VIN_REV -> Q2 -> VIN_BUCK -> U1 VIN
J1-2 GND ---------------------------------------------------------------> U1 GND

防反接：
Q1-D = VIN_FUSED
Q1-S = VIN_REV
Q1-G = REV_GATE
REV_GATE -> R1 -> GND
REV_GATE -> R2 -> VIN_REV
D1 跨接 VIN_REV 与 REV_GATE，钳位 Q1 的 Vgs

限压和过压关断：
Q2-S = VIN_REV
Q2-D = VIN_BUCK
Q2-G = PASS_GATE
PASS_GATE -> R3 -> VIN_REV
PASS_GATE -> R4 -> Q3-C
D3 跨接 VIN_REV 与 PASS_GATE，钳位 Q2 的 Vgs

VCC_CTRL 由 VIN_REV 经 R7 和 D4 产生
U2 TL431B 产生 VREF_2V495
U3A 比较 VREF_2V495 与 CLAMP_FB，控制 Q3，令 VIN_BUCK 约等于 31.94V
U3B 比较 OVP_DIV 与 VREF_2V495，超过约 36.9V 后关断 Q2 并点亮 OVP_FAULT

Buck 主回路：
U1 VIN = VIN_BUCK
U1 SW -> SW -> L1 -> VOUT_REG
U1 BST -> BST -> C14 -> SW
VOUT_REG -> C16/C17/C18 -> GND

反馈和输出：
VOUT_REG -> R20 -> FB -> R21 -> GND
C19 并联在 VOUT_REG 与 FB 之间
VOUT_REG -> J2 I-MEAS -> VOUT_5V -> J3-1
J3-2 -> GND
VOUT_5V -> R22 -> LED2 -> GND
```

## 关键计算

```text
Buck 实际输入限压：
V_BUCK_LIMIT = 2.495V * (1 + R9 / R10), R9 = R9A + R9B
             = 2.495V * (1 + (100k + 18.0k) / 10.0k)
             = 31.94V
```

```text
过压关断阈值：
V_OVP = 2.495V * (1 + R11 / R12), R11 = R11A + R11B
      = 2.495V * (1 + (120k + 18.0k) / 10.0k)
      = 36.93V
```

```text
36V 满载前级功耗估算：
Pout = 5V * 2A = 10W
假设 Buck 效率 85%，Pin ≈ 10W / 0.85 = 11.76W
Iin ≈ 11.76W / 31.94V = 0.37A
P_QPASS ≈ (36V - 31.94V) * 0.37A = 1.5W

结论：
Q2 必须用 TO-252 或更大封装，大铜皮散热并加过孔导热；36V、5V/2A 短时满载必须记录 Q2、U1、L1 温升。
```

```text
F1 自恢复保险丝选型：
18V 输入、5V/2A 满载时，输入电流约 10W / (18V * 0.8~0.85) ≈ 0.65A~0.70A。
考虑启动浪涌、输入电容充电和 PTC 高温降额，0.75A 或 1.1A hold 偏贴边。
本版选 60V、Ihold=1.5A、Itrip=3A 的 SMD2920-150/60N，正常工作不易误断，输入短路/严重故障仍能限流保护。
```

```text
Vout = 0.6V * (1 + R20 / R21)
     = 0.6V * (1 + 110k / 15.0k)
     = 5.00V
```

```text
GD30DC1354 手册要点：
VIN 推荐工作范围 4.5V~36V，赛题要求 18V~36V 输入。
本方案让 36V 外部输入时 U1 实际 VIN 约 31.94V，不让芯片长期顶在推荐上限。
EN 悬空默认使能；EN/FB 属于 I/O 脚，绝对最大约 6V，不能接输入高压；本板只预留 EN 到 GND 的 100kΩ DNP 调试下拉位。
5V/2A 参考设计使用 L=15uH、C14=100nF、C19=75pF。
```

## PCB 注意事项

- `Q2` 是 36V 满载时的主要发热点之一，TO-252 焊盘必须接大面积顶层铜皮，底层同步铺铜，并用过孔阵列导热。
- `VIN_REV -> Q2 -> VIN_BUCK -> U1 VIN` 主电流路径要短而宽，建议 60mil 以上或直接铺铜。
- `D2` 到 GND、`D5` 到 GND 的回流路径必须最短，旁边放 GND 过孔。
- `C9/C10/C11/C12` 必须贴近 U1 VIN 和 GND；`R17+C13` 放在 VIN_BUCK 入口附近。
- `SW` 铜皮只保留 U1 SW 到 L1 的必要面积，远离 `FB`、`CLAMP_FB`、`OVP_DIV`、输出端子和板边。
- `R20/R21/C19` 紧贴 U1 FB；`R20` 从输出电容正端 Kelvin 取样。
- `CLAMP_FB` 和 `OVP_DIV` 是高阻检测点，走线短、远离 SW 和电感；分压下端就近回到干净 GND。
- J2 用额定 3A 以上短接帽或端子；PCB 丝印写 `I-MEAS SHORT NORMAL`。
- 底层尽量完整铺 `GND`，不要在 U1 GND、输入电容地、输出电容地、控制电路地之间割裂。
