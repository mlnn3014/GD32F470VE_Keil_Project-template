## 关键计算

```text

图中 R6=20kΩ, R7=200Ω。

```

```text
INA333 一级增益：
RG = R8 = 20kΩ
G1 = 1 + 100kΩ / 20kΩ = 6

若 PT100 电流为 1mA：
-50°C:  R=80.31Ω,  Vpt≈80.31mV,  Vina_out≈481.9mV
0°C:    R=100Ω,    Vpt≈100.0mV,  Vina_out≈600.0mV
150°C:  R=157.33Ω, Vpt≈157.33mV, Vina_out≈944.0mV
```

```text
OPA333 二级近似传递函数：
R13=47kΩ, R14=11kΩ, R15=20kΩ
Vadc_pre ≈ Vin * (1 + R15/R14 + R15/R13) - 2.5V * (R15/R13)
         ≈ Vin * 3.244 - 1.064V

-50°C: 约 0.50V
0°C:   约 0.88V
150°C: 约 2.00V

若 GD30AD3344 配置 PGA=±2.048V，最高点约占正量程 98%，不满足题目 20%~80% 量程要求。

```

```text

R18=500Ω, C9=4.7nF
fc≈1/(2*pi*500Ω*4.7nF)≈67.7kHz
```

## 设计评估

### 优点

- 使用 `LT3092` 做高边恒流源，思路清晰，电流设定元件少，理论上容易得到约 1mA 激励。
- 使用 `INA333` 做仪表放大，符合题目“差分放大/仪表放大”要求。
- 使用 `REF3025` 给 AIN3 提供 2.5V 基准，方向符合题目“ADC 基准电压源”要求。
- SPI 四线均预留 51Ω 串联电阻，符合题目 SPI 接口串阻要求。
- 尝试区分 `GND/AGND`，并用 `R5=0Ω` 单点连接，方向正确。

### 主要问题

1. **传感器电流回路不闭合或依赖外部短接**  
   `LT3092` 输出 `1MA` 后，PT100 电流应经过传感器回到地或低边恒流回路。图中 `EXC-` 只进入 INA333 高阻输入，板上没有明确回到 `AGND` 的电流路径。若外部测试板不额外把 `EXC-` 接到 `AGND`，恒流源没有完整回路，采样可能不工作。

2. **CN1 把 `SENSE+` 与 `1MA` 在板端同点连接，削弱三线 Kelvin 意义**  
   三线制应让激励红线与红端采样线只在 PT100 红端或测试板 Kelvin 点汇接。CN1 图面显示 `SENSE+` 与 `1MA` 在采样板端同点，若使用 CN1，红线压降补偿会被破坏。

3. **SPI MOSI/MISO 命名疑似反接**  
   U1 `DIN` 接到 `GD_MISO`，U1 `DOUT/DRDYN/ALERT` 接到 `GD_MOSI`；H1 侧也出现 `GD_MOSI -> MISO`、`GD_MISO -> MOSI` 的交叉。按常规定义和本工程固件，ADC `DIN` 应接 MCU `MOSI`，ADC `DOUT` 应接 MCU `MISO`。此处若按图打样，大概率 SPI 通信失败。

4. **二级放大后的 ADC 量程不满足题目 20%~80% 要求**  
   估算输出在 -50°C~150°C 约 `0.50V~2.00V`。对 `±2.048V` 档，高端接近满量程；对 `±4.096V` 档，低端低于 20%。题目明确要求计算放大倍数并匹配 20%~80%，这一项容易被扣分。

5. **AIN0 RC 滤波截止频率过高**  
   `500Ω + 4.7nF` 截止约 `67.7kHz`，不适合作为题目期望的 ADC 输入低通滤波说明。建议改到几十 Hz 到几百 Hz，并配合低采样率/软件平均。

6. **AIN0 的 `R17=1MΩ` 到 A3V3 会引入额外偏置**  
   OPA333 输出经 `R16=10kΩ` 驱动 ADC 节点，`R17=1MΩ` 到 `A3V3` 会给 `ADC` 节点引入约几十 mV 的偏移，需纳入公式或删除/改为 DNP。

7. **基准源规格偏弱于满分冲刺方案**  
   `REF3025` 可以用，但相比 `REF5025`，精度、温漂和噪声说服力较弱。若目标是“满分”和答辩可解释性，REF5025 更稳。

8. **缺少 AIN1/AIN2 诊断补偿通道**  
   该图把 AIN1/AIN2 悬空，不能读取红端 Kelvin 电压和激励电压，也就无法解释或补偿真实三线 PT100 的引线残余误差。

## 建议修改

### 必须修改

- 修正 SPI：`U1 DIN -> MCU MOSI`，`U1 DOUT/DRDYN/ALERT -> MCU MISO`，同时统一 H1 丝印和网络名。
- 明确 PT100 电流回路：若保留高边 LT3092，`EXC-` 必须有受控回流到 `AGND` 的路径；或者改为低边恒流 sink，使 `1MA/RED_FORCE -> PT100 -> EXC-/WHITE -> sink -> AGND` 闭环清晰。
- 统一传感器端子，只保留一个标准三线接口：`WHITE/EXC-`、`RED_FORCE/1MA`、`RED_SENSE/SENSE+`；`RED_FORCE` 与 `RED_SENSE` 不在采样板上短接。

### 强烈建议

- 简化模拟链路：取消 OPA333 二级偏置放大，改为 INA333 直接输出到 AIN0，并把 INA333 增益改到约 `10.09`，可得到 `0.81V~1.59V`，刚好满足 `±2.048V` 档 `39%~78%`。
- 若坚持两级方案，重新计算 R13/R14/R15，让 -50°C~150°C 对应输出落在当前 ADC 档位的 `20%~80%` 内，并把公式写入方案书。
- 把 AIN0 滤波改为例如 `1kΩ + 3.3uF` 或类似几十 Hz 量级，同时在方案书中说明工频稳定由低速采样和软件平均配合完成。
- `R17/R20` 建议删除或 DNP，避免不必要的偏置和参考负载。
- 将 `REF3025` 升级为 `REF5025`，或至少补充 REF3025 初始精度、温漂、负载电流对测温误差的估算。
- 利用 GD30AD3344 空闲通道：`AIN1=RED_SENSE_MON`，`AIN2=VFORCE_MON`，用于三线引线压降诊断和答辩展示。

## 满分判断

按当前 PDF 原理图直接打样，**不建议冲满分**。设计思路有可取之处，但存在 SPI 接线疑似反、PT100 电流回路不闭合、三线接口不标准、量程映射不满足 20%~80%、滤波截止频率过高等硬伤。

粗略判断：

| 评分项 | 当前风险 |
| --- | --- |
| 信号调理电路设计 | 恒流源思路有分，但回路和量程问题明显，风险高 |
| ADC 外围电路设计 | 有基准、去耦、SPI 串阻，但 SPI 命名/连接疑似反接 |
| PCB 布局布线质量 | 仅凭原理图无法判断；需后续看 PCB |
| 传感器/测试板接口 | CN1/CN2 定义不统一，三线 Kelvin 解释风险高 |
| SPI 通信功能 | 若 DIN/DOUT 确实反接，功能演示会直接失败 |
| 基础/进阶精度 | 即使硬件能读数，也需重算量程和标定；当前不能稳拿 |

结论：**这版可作为“参考思路草图”，不建议作为最终满分提交版。**  
若按上面的必须修改项修正，并采用 `INA333 直接约 10 倍 + AIN1/AIN2 监测补偿 + REF5025 + 清晰三线接口`，才更接近满分稳态方案。
