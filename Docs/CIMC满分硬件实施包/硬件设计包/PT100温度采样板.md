# PT100 温度采样板

## 页面目标

完成一块独立双层 PCB，用 `GD30AD3344` 读取三线制 PT100 或模拟测试板。本页按“元件位号”为单位写原理图连接；在 EDA 里给引脚放同名 NetLabel 即可连通，不需要把所有线拉成长线。

| 项目 | 内容 |
| --- | --- |
| 板名 | `PT100 温度采样板` |
| 输入 | 三线制 PT100 或模拟测试板 |
| ADC | `GD30AD3344AMTR-I` |
| 基准路线 | `REF5025 2.500V -> GD30AD3344 AIN3`，固件调用 `ad3344_ExtRef()` 使能 AIN3 外部参考 |
| 模拟前端 | `1.25V 激励 + 1.000mA 低边恒流 sink + INA333 仪表放大 + AIN1/AIN2 三线补偿监测` |
| MCU 接口 | GD32F470 `SPI3`：PE2/PE5/PE6/PE4 |
| 丝印 | `PT100 温度采样板 队伍编号 2026-05` |

这版是满分冲刺最终版：保留赛题要求的恒流源、差分/仪表放大、ADC 输入滤波、外部基准、SPI 串阻和模拟/数字地单点连接，同时把模拟前端收敛为更容易画图和调试的单恒流 sink 结构。额外用 GD30AD3344 的 AIN1/AIN2 监测 `RED_SENSE` 与 `RED_FORCE`，用于解释和补偿三线制红线/白线等阻假设下的引线压降。

## 固定网络名

| 网络名 | 含义 |
| --- | --- |
| `AGND` | 模拟地，传感器、电源基准、运放模拟地 |
| `DGND` | 主排针输入的外部数字地，通过 NT1 与 AGND 单点连接 |
| `3V3_D` | J1 输入的外部/开发板数字 3.3V |
| `3V3_A` | 由 `3V3_D` 经 FB1/0Ω/磁珠滤波得到的模拟 3.3V |
| `VREF_2V5` | REF5025 输出的 2.500V 精密基准 |
| `AIN3_REF` | 送入 GD30AD3344 AIN3 的外部基准 |
| `VFORCE_DIV` | 1.25V 激励分压原始节点 |
| `VISET_DIV` | 0.25V 恒流设定分压/滤波节点 |
| `VISET_250M` | R7 隔离后送入 U3 B路 + 输入的 0.25V 恒流设定电压 |
| `ISINK_GATE` | 低边 NMOS 恒流 sink 栅极 |
| `ISINK_SOURCE` | 低边 NMOS 源极和恒流采样电阻上端 |
| `WHITE` | PT100 白线，恒流回流端 |
| `RED_FORCE` | U3 A路输出的 1.25V 激励网络，直接连接 PT100 激励红线 |
| `RED_SENSE` | PT100 采样红线，只做高阻 Kelvin 采样 |
| `PT100_DIFF_P` | INA333 正输入，RED_SENSE 滤波后 |
| `PT100_DIFF_N` | INA333 负输入，WHITE 滤波后 |
| `PT100_AMP_OUT` | INA333 放大输出 |
| `PT100_ADC` | GD30AD3344 AIN0 输入节点 |
| `RED_SENSE_MON` | RED_SENSE 经 RC 滤波后的 AIN1 监测节点 |
| `VFORCE_MON` | RED_FORCE 经 RC 滤波后的 AIN2 监测节点 |
| `SPI_SCK` | SPI 时钟 |
| `SPI_MISO_DRDY` | ADC DOUT/DRDY |
| `SPI_MOSI_DIN` | ADC DIN |
| `SPI_CS` | ADC 片选 |

说明：`RED_FORCE` 和 `RED_SENSE` 在采样板上绝对不要短接。它们只在 PT100 探头红端，或模拟测试板的 `RED_KELVIN` 点汇接。`RED_FORCE` 提供激励电压和电流，`RED_SENSE` 只把红端真实电压送给 INA333 高阻输入。

## 电路连接拓扑图

```text
电源和地：
J1-1 3V3_D -> FB1/0Ω/磁珠 -> 3V3_A
3V3_D -> C2/C3/C22/C23 -> AGND
3V3_A -> C4/C5 -> AGND
J1-2 DGND ---------------------> NT1 -> AGND

外部基准：
3V3_A -> U2 REF5025 -> VREF_2V5 -> R1 -> AIN3_REF -> U6 AIN3
AIN3_REF 只给 GD30AD3344 做外部转换参考，不再当普通模拟通道使用

1.25V 激励和 1mA 低边恒流：
VREF_2V5 -> 10k/10k 分压 -> U3 A路缓冲 -> RED_FORCE
VREF_2V5 -> R4/R6 分压 -> R7 -> U3 B路 + Q1 + R9 -> 约 1.000mA sink

传感器电流路径：
RED_FORCE -> PT100/测试电阻 -> WHITE -> Q1-D -> Q1-S -> R9 -> AGND
RED_SENSE 只在 PT100 红端/测试板 RED_KELVIN 与 RED_FORCE 汇接，然后高阻采样

放大和 ADC：
RED_SENSE -> R10 -> PT100_DIFF_P -> U4 INA333 IN+
WHITE     -> R11 -> PT100_DIFF_N -> U4 INA333 IN-
U4 REF=AGND, R12=11.0kΩ, OUT -> R13/C19 -> PT100_ADC -> U6 AIN0
RED_SENSE    -> R14/C20    -> RED_SENSE_MON -> U6 AIN1
RED_FORCE    -> R15/C21 -> VFORCE_MON    -> U6 AIN2

数字接口：
U6 SCLK/CS/DOUT/DIN -> 51R 串阻 -> J1 -> GD32F470 PE2/PE4/PE5/PE6
```

## 关键计算

```text
1.25V 激励电压：
RED_FORCE = 2.500V * 10.0kΩ / (10.0kΩ + 10.0kΩ) = 1.250V

0.25V 恒流设定：
R4 = 90.0kΩ
VISET = 2.500V * 10.0kΩ / (90.0kΩ + 10.0kΩ) = 0.2500V

低边恒流：
Ipt100 = VISET / R9 = 0.2500V / 250.0Ω = 1.000mA

PT100 自热：
Pmax = 157.33Ω * (1mA)^2 = 0.157mW
```

```text
INA333 增益：
R12 = 11.0kΩ
G = 1 + 100kΩ / R12 = 1 + 100kΩ / 11.0kΩ ≈ 10.09

-50°C:  Rpt100=80.31Ω,  Vpt≈80.31mV,  Vadc≈80.31mV*10.09≈0.81V
0°C:    Rpt100=100Ω,    Vpt≈100.00mV, Vadc≈100.00mV*10.09≈1.009V
150°C:  Rpt100=157.33Ω, Vpt≈157.33mV, Vadc≈157.33mV*10.09≈1.59V

GD30AD3344 配置 PGA=±2.048V 时，AIN0 正量程利用约 39%~78%，满足赛题 20%~80% 要求。
```

```text
ADC 输入低通：
fc = 1 / (2*pi*R13*C19)
   = 1 / (2*pi*1kΩ*3.3uF)
   ≈ 48Hz

AIN1/AIN2 监测低通：
fc = 1 / (2*pi*1kΩ*100nF) ≈ 1.59kHz
这两路只用于慢速诊断和三线补偿，主精度仍由 INA333 差分链路、AIN0 低通和软件平均保证。
```

```text
三线补偿：
AIN1 = RED_SENSE_MON ≈ PT100 红端真实电压
AIN2 = VFORCE_MON ≈ RED_FORCE 输出电压
Vlead_red = AIN2 - AIN1
Vdiff = AIN0 / G
Vpt100 = Vdiff - Vlead_red
Rpt100 = Vpt100 / Ipt100

比赛模拟测试板短线接入时 Vlead_red≈0，补偿项几乎不改变结果。
真实三线 PT100 长线接入时，若两根红线和白线等长等阻，可用红线压降估算并抵消白线回流残余误差。
```

```text
GD30AD3344 手册/官方例程要点：
VDD 范围 2.7V~5.5V，本板用 3.3V。
模拟输入必须保持在 GND~VDD 内，本板 AIN0 约 0.81V~1.59V，AIN1/AIN2 约 1.25V 附近，AIN3_REF 约 2.5V。
配置寄存器支持 AIN0/AIN1/AIN2 单端轮询、PGA=±2.048V、DR=6.25SPS/12.5SPS。
官方 ExtRef 例程提供 ad3344_ExtRef()，用于使能 AIN3 作为外部参考源。
```

## 三线接口与标定说明

- 本板保留标准三线端子：`WHITE / RED_FORCE / RED_SENSE`，可以接真实三线 PT100，也可以直接接模拟测试板。
- `RED_FORCE` 承担激励电流，`RED_SENSE` 为高阻 Kelvin 采样线，二者只在 PT100 红端或测试板 `RED_KELVIN` 同点汇接，因此激励红线上的压降不会进入 INA333 的红端采样。
- `WHITE` 同时承担回流和白端采样。真实长线 PT100 的白线电阻会形成残余误差；固件读取 AIN2/AIN1 得到 `VFORCE_MON-RED_SENSE_MON`，用红线压降在等长等阻假设下抵消白线残余误差。
- 比赛演示使用短线测试板时 `Vlead_red≈0`，补偿项几乎不改变结果，最终再用 12 点实测标定表吸收电阻实装误差。
- 方案书中写法：本设计采用“红端 Kelvin + 低边恒流 + AIN1/AIN2 引线压降监测补偿 + 分段标定”的三线兼容方案，优先保证赛题测试板演示稳定、ADC 量程利用率满足 20%~80%、外部基准链路可展示，并能解释真实三线 PT100 的引线误差处理。

## 画图步骤

1. 先画 `J1/C2/C3/C4/C5/FB1/NT1`，确认 `J1-1 3V3_D -> FB1 -> 3V3_A`，且 `J1-2 DGND` 只通过 `NT1` 单点连接到 `AGND`。
2. 画 `U2/C6/C7/C8/C9/C10/R1/C11`，确认 `VREF_2V5 -> R1 -> AIN3_REF -> U6 AIN3`，AIN3 不再接别的模拟信号。
3. 画 `R2/R3/C13/U3` 的 A 路，得到 `RED_FORCE`，并确认 U3 OUTA、U3 -INA、J2-2、R15-1、TP6 都是同一个网络。
4. 画 `R4/R6/C14/R7/U3/R8/Q1/R9`，其中 U3 使用 B 路，得到 1mA 低边恒流 sink：`WHITE -> Q1 -> R9 -> AGND`。
5. 画 `J2/R10/R11/C15/C16/C17/U4/R12`，让 INA333 直接放大 `RED_SENSE - WHITE`。
6. 画 `R13/C19/R14/C20/R15/C21/U6/R16/R17/R18/R19/J1`，完成 AIN0 主采样、AIN1/AIN2 监测和 SPI。
7. 最后放所有测试点，测试点只接网络，不改变主信号路径。

## PCB 注意事项

- J2、输入滤波、INA333、ADC 按信号流从左到右放置；U3/Q1/R9 靠近 J2 的 `WHITE` 回流路径。
- `RED_FORCE` 和 `RED_SENSE` 在采样板上不要短接；它们只在 PT100 探头红端或模拟测试板 `RED_KELVIN` 点汇接。
- `PT100_DIFF_P`、`PT100_DIFF_N` 走线短、并行、远离 SPI 和电源开关节点。
- `RED_FORCE` 是低噪声 1.25V 激励线，不要和 SPI 并行长距离走线。
- `U2 REF5025` 放在安静模拟区，周围用 `AGND` 护地，远离电源板、电感和 SPI 排针。
- `R13/C19` 靠近 U6 AIN0；`R14/C20` 靠近 U6 AIN1；`R15/C21` 靠近 U6 AIN2；`C11` 靠近 U6 AIN3。
- U6 GND 回到 `AGND` 星点，J1 的 `DGND` 通过 `NT1` 在 U6 附近单点汇接。
- SPI 串阻靠近 U6，SPI 线从 J1 数字侧出，不穿过 J2 和 INA333 输入区。
- J1-1 是本板唯一 3.3V 输入；不要再从其它接口给 `3V3_A` 或 `3V3_D` 并联供电。
